# GSE288958-DMD-Satellite-Cell-Precision-Medicine

## Single-nucleus transcriptomic analysis of Duchenne muscular dystrophy

This repository contains the analysis scripts, publication figures, and selected results supporting the study of satellite-cell states and DMD-associated molecular programs using single-nucleus RNA-sequencing data from GSE288958.

## Dataset

GEO accession: **GSE288958**

Samples analyzed:
- Normal: 5 samples
- Becker muscular dystrophy (BMD): 3 samples
- Duchenne muscular dystrophy (DMD): 3 samples

## Study workflow

1. Single-nucleus RNA-seq preprocessing and quality control
2. Global cell-state identification
3. Satellite-cell identification and reclustering
4. Satellite-cell state characterization
5. Identification of DMD-associated State 4
6. Sample-aware molecular signature analysis
7. Regulatory and mechanistic characterization
8. Cellular-state and molecular-signature integration
9. Therapeutic candidate prioritization
10. Precision-medicine framework development
